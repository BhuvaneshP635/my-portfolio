
# Bhuvanesh - Personal Portfolio

A colourful, responsive personal portfolio built using HTML, CSS and vanilla JavaScript.

## Features

- Responsive layout for desktop and mobile
- Dark and light themes
- Animated hero section
- Professional journey timeline
- Personal interests, family and hobbies
- Scroll reveal animations
- GitHub Actions CI/CD
- GitHub Pages deployment

## Technologies

- HTML5
- CSS3
- JavaScript
- Git and GitHub
- GitHub Actions
- GitHub Pages

## Run locally

Open `index.html` in a browser.

## Deployment

The production website is deployed to GitHub Pages from the `main` branch.
